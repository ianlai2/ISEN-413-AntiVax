## How to Use
### Model Architecture
```
Input (123 features, after removing 13 redundant)
    ↓
Dense(128, relu) → Dropout(0.3)
    ↓
Dense(64, relu) → Dropout(0.3)
    ↓
Dense(32, relu) → Dropout(0.3)
    ↓
Dense(1, sigmoid)
```

### Class Imbalance Handling
Available sampling methods:
1. **None** (default) - No sampling
2. **Random Oversampling** - Duplicate minority samples
3. **Random Undersampling** - Remove majority samples
4. **SMOTE** - Generate synthetic samples (recommended)
5. **SMOTE + Tomek Links** - SMOTE + boundary cleaning
6. **SMOTE + ENN** - SMOTE + noise removal

Configuration:
```yaml
sampling:
  method: "smote"  # or none, oversample, undersample, smote_tomek, smote_enn
  k_neighbors: 5
  sampling_strategy: "auto"
```

### Data Preprocessing
- **Feature Scaling**: StandardScaler (z-score normalization)
- **Feature Removal**: 13 constant features removed (Q312_1, Q312_2, Q54_3, Q64_1-3, Q65_1, Q66_3, Q67_2-3, Q69_1-3)
- **Final Features**: 123 (reduced from 136)
